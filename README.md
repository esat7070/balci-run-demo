# Balci Run – Demo

**▶️ Spielen: https://esat7070.github.io/balci-run-demo/**

Die Demo von *Balci Run – Yusufs Honig-Jagd*: ein handgepixeltes Jump'n'Run
im Browser (PC und Handy, Controller geht auch). Yusuf Balci will eigentlich
nur Honig. Samstag, 6:45 Uhr — und schon stehen ihm Mirkan, Lennart, Erfan und
Huseyin im Weg.

- **5 Level**, 4 Bosse mit je drei Herzen und drei Formen
- Honig und Goldhonig sammeln, Trophäen, Bestenliste im eigenen Browser
- Kein Game Over: weiter geht es immer am letzten Checkpoint

## Steuerung

| Taste | Was passiert |
|---|---|
| `←` `→` oder `A` `D` | Laufen |
| `Leertaste` / `W` / `↑` | Springen — nochmal in der Luft: **Bauch-Boost** |
| `↓` in der Luft | **Bauch-Stampfer** — zerbricht Kisten, plättet alles in der Nähe |
| `Shift` / `E` | Rennen + **Kippe werfen** |
| `Esc` / `P` | Pause |
| `M` | Ton an / aus |

Am Handy blenden sich Knöpfe ein, ein Controller geht auch.

Die Vollversion hat 30 Level. Diese Seite wird automatisch aus dem
(privaten) Hauptprojekt erzeugt.
